# Gio (fork)

Immediate-mode GUI for Go — fork of [gioui.org](https://gioui.org).

Targets macOS, Linux, FreeBSD, OpenBSD, Windows, and WebAssembly.

This fork is maintained for our own use; no support is provided for external consumers and breaking changes may land at any time. For the upstream library see [github.com/gioui/gio](https://github.com/gioui/gio).

github.com/nanorele/gio
